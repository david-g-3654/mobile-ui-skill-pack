# Pre-registration: judging pack 0.4

Written **2026-10-15, before any 0.4 screen was generated or judged.** It fixes what will be run, how it will be scored, and what will be published, so the result can't be shaped after the fact.

## Why this run

Every published result so far judged an older pack: SwiftUI on 0.2, React Native on 0.2+, Flutter on 0.3. Since then, 0.4 added the `Q…` renames, the change-line fix and `QBarChart`. This run judges **the version people install**.

## Commitment

1. **The results will be published whatever they show:** win, loss or tie, per platform and per judge, including any screen that fails to build.
2. **The earlier runs stay in the record** unchanged (`evals/results/2026-10-14-*`, the cross-family folders, `scores.csv`). 0.4 is added alongside them, not swapped in.
3. **One run, no retries.** Each prompt is generated once per platform. No regenerating a screen that loses, and no re-judging a pair whose verdict is inconvenient. If a judge's reply can't be parsed, that pair is re-asked once, and the retry is reported.
4. **The pack is frozen for the run.** If a pack bug turns up mid-run, it's written down and fixed only after the 0.4 results are published.

## Protocol

| | |
|---|---|
| Prompts | The same 8 user requests (home, settings, paywall, onboarding, detail, list, stats, auth) |
| Platforms | SwiftUI, React Native (Expo SDK 57), Flutter, rendered on the iPhone 17 / iOS 27 simulator in light, dark and accessibility-XL text |
| With-pack arm | One new generation per prompt per platform on pack 0.4, by Claude Opus 5.5. Prompts are in `evals/prompts/<platform>-v0.4/generate/`: the previous runs' prompts with only output paths changed, plus the instruction not to read `evals/` or `docs/` |
| Without-pack arm | The same baseline screens as before: no regeneration, same code. SwiftUI and Flutter reuse their existing captures. **React Native's baseline is recaptured from a release build**, because the old captures came from Expo Go, with its dev-tools button and, on two screens, a warning bar. The new pack screens will also be release builds, so both sides look the same |
| Blind pairs | Random A/B per prompt (new seed per platform), both orderings, so 16 pairs per platform and 48 in total. Generated by `evals/tools/compose_pairs.py`; the key never reaches a judge |
| Judges | **Claude Opus 5.5** (one fresh agent per pair, same prompt as earlier runs), **GPT-6.1 Sol** and **Grok 4.7** (via OpenRouter, `judge_external.py`, same images, request, rubric and schema). Every pair goes to all three judges |
| Scoring | `evals/tools/unblind.py`: judgments won, prompts won in both orderings, one-sided sign test over decided prompts, mean rubric scores. Reported per platform × judge, plus agreement and a two-of-three majority |
