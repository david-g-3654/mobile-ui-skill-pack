# Scoring rubric (1–5 per criterion)

Score each screenshot set (light, dark, large text) without knowing which arm produced it.

| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| **Focal hierarchy** | Everything equal weight; can't tell what matters | A focal element exists but competes | One element clearly dominates; eye path is obvious |
| **Restraint** | Card soup, icon confetti, gradients, many colors | Some decoration that doesn't earn its place | Every element earns its place; accent ≤2 uses |
| **Typography** | 6+ sizes or all bold; numbers jitter/misaligned | Reasonable but flat | Clear ramp, 2 weights, tabular numbers, units de-emphasized |
| **Spacing & alignment** | Cramped or random; mixed margins | Mostly consistent | 4pt rhythm, consistent margins, grouping by proximity |
| **Platform fit** | Fake nav bars, web-like controls, ignores safe areas | Native-ish with some hand-rolled chrome | Feels native: navigation, sheets, controls, gestures |
| **Dark mode** | Missing or inverted (shadows, same accent) | Works but flat | Designed: surface steps, adjusted accent, no shadows |
| **Accessibility** | Breaks at large text; unlabeled icons; low contrast | Mostly OK | Survives XXL text; contrast passes; labels present |
| **Content realism** | Lorem / John Doe / identical rows | Plausible but bland | Specific, varied, domain-true |
| **States** (when asked or when list-based) | None | One of empty/loading/error | All designed in the final layout |

**Overall** = mean of applicable criteria. Also record a **pairwise preference** (A/B/tie) for each prompt × platform pair: "Which one looks like a designer worked on it?"
